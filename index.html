Swamped? Your house’s agents bid to bail you out.

Every roommate gets a personal agent. When one of you is buried in deadlines, the agents bid on your chores. Whoever minds it least takes it, earns favor credits, and gets paid back when they’re the one drowning.

Nobody ever learns why you’re busy.

Plain code decides who wins and what it costs. The language model only writes the messages.

The auction and the ledger are ordinary, tested Python. A model never sees your private numbers, so it can’t leak them.

The ledger remembers, so nobody has to

Credits are favors, not money, and the ledger always adds up to zero. When Jordan is the one drowning, his agent asks Maya’s agent first, because she owes him the most. Both of them say yes before anything moves.

Try it with your house

Join a house

  1. Join the house’s Discord and allow DMs from server members.
  2. Type /join in #agent-floor.
  3. Set your private profile with /me busy, /me dislike and /me cap.
  4. Optional: install the Bailout Link skill on your Cubbie so your busy level comes from Canvas.

Start a house

  1. Clone the repo and install the three Python packages.
  2. Create a Discord bot, turn on Message Content, and invite it.
  3. Make an #agent-floor channel and fill in .env.
  4. Run python3 bot.py, then /help.
